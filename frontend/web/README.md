# 💻 CropGuard Market — Web Portal (React.js / Vite)
**Track:** DE / Web (Data Engineering & Web)  
**Tech Stack:** React.js (Vite) + Tailwind CSS + Recharts + Axios

---

## 🎯 Scope & Objectives
1. Bulk Wholesaler & Institutional Buyer procurement dashboard (50+ quintals).
2. UASD Dharwad & ICAR market monitoring analytics panel.
3. Live APMC Mandi Rate Benchmark data pipeline & price fluctuation graphs.
4. Transaction audit and fair-trade compliance reporting.

## 🚀 Getting Started
```bash
cd web
npm install
npm run dev
```
